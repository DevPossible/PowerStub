## PowerStub 2.1.2

- A stub command can now run another stub command, through `pstb` or a direct alias. Before, the inner call failed with `Sync-PowerStubConfiguration: Cannot index into a null array.`, because the outer script ran inside PowerStub's own module scope and hid PowerStub's settings while it ran.
- Commands now run outside PowerStub's module scope. Exit codes, `$?`, `&&`/`||` chains and output streams behave as before.
