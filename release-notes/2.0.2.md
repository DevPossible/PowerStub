## PowerStub 2.0.2

- Direct aliases invoked without arguments now show the same command table as `pstb <stub>`, sorted by command name with summaries from `.SYNOPSIS` headers, instead of returning a directory listing.
- Scripts without recognized help headers show `-` instead of generated file names or parameter syntax. Executables continue to use their metadata synopsis.
- Existing prerelease visibility, command execution, and failure-status behavior are retained.

Reload the updated module with `Remove-Module PowerStub; Import-Module PowerStub` to recreate saved direct aliases with the fixed behavior.
