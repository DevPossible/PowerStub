## PowerStub 2.4.0

- PowerStub now tells you when a newer release is on the PowerShell Gallery: `A newer version of PowerStub is available (<latest>, you have <installed>). Run 'Update-Module PowerStub' to install it.`
  - Checked at most once a day, in a hidden background process, so commands never wait for it. The notice appears on a later run, once per PowerShell session.
  - Only copies installed from the Gallery are checked. Git is not needed.
  - Set `ReleaseCheckIntervalHours` in the config file to change the interval, or to `0` to turn it off. `POWERSTUB_NO_UPDATE_CHECK`, CI jobs and `-NonInteractive` sessions also turn it off.
- The stub command list shows alpha and beta commands first, marked `* name` instead of `name *`.
