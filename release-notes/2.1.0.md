## PowerStub 2.1.0

- Running a command from a stub in a Git repository now tells you when that repository is behind its remote: `You do not have the latest version of 'DevOps' (3 commit(s) behind). Run 'pstb update DevOps' to get the latest version.`
- The check never slows commands down. It runs `git fetch` in a hidden background process at most every 4 hours per stub, and the result is shown on a later run, once per repository per session.
- Set `UpdateCheckIntervalHours` in the config file to change the interval, or to `0` to turn it off. Setting the `POWERSTUB_NO_UPDATE_CHECK` environment variable also turns it off. CI jobs and `-NonInteractive` sessions are never checked.
- Nothing changes when Git is not installed, when Git integration is disabled, or for stubs outside a Git repository. Stubs inside and outside repositories can be mixed.
