## PowerStub 2.1.1

- Listing a stub's commands (`pstb <stub>` or a bare direct alias) is fast again: a 49-command stub took over 15 seconds and now takes well under a second. Synopses are read straight from each script's help block instead of through `Get-Help` with a wildcard pattern, which searched every command and help topic on each call.
- `pstb search` is faster for the same reason, and `pstb help` no longer pays the wildcard search cost for ordinary file names.
- Scripts without a help block now show `-` in command listings, instead of a generated syntax line.
