## PowerStub 2.2.1

- Running a stub command no longer prints `Invoking <command file>` every time, which flooded the console when commands were called in loops. The line is now verbose-only: pass `-Verbose` to the command (it still reaches the command too) or set `$VerbosePreference = 'Continue'`, and PowerStub writes `VERBOSE: Invoking <command file>`.
- Output through `pstb` and direct aliases now matches a direct call record for record, with no extra information-stream line.
